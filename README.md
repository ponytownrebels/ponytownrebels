<h1 align=center> Welcome To The Rebellion </h1>
<p align=center>This is a <b>decentralized</b> ponytown group based off the Rebels from Evade (Roblox). You don't need to know anything about Evade to join, don't worry. There are no leaders or management; every Rebel is equal. If you're organizing an event and would like me to advertise it on this page, just let me know <a href=https://ponytownrebels.atabook.org/>Here</a>. Shoot me a message if you'd also like to be added to the directory.</p>
<h1 align=center>How do I join? </h1>
<p align=center>
  Joining is quite simple! There are no applications and no review process, you need no one's permission to become a Rebel. All you must do is link this profile on your main github profile, and dress up as a Rebel.
</p>
